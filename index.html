The GymPro Compatibility Standard

We discover inspiration and components from sources such as 21st.dev, then inspect, adapt and verify them before they enter this catalogue. Third-party code is never shipped directly as an executable GymPro asset.

01 · Safe by designData-only package formats; no downloaded JavaScript, HTML, arbitrary CSS or remote frames.
02 · GymPro renderer fitOnly supported renderers: canvas_shader, svg_vector and css_micro.
03 · Lightweight & accessibleReduced-motion behavior, high-DPI handling, CPU budget and off-screen pausing reviewed where applicable.
04 · Theme-awareWorks with GymPro Base Theme and Integrated Studio Canvas Tone, including frosted-glass surfaces.
05 · Licence & provenanceSource, author, licence and attribution are recorded; incompatible terms are rejected.
06 · Integrity verifiedExact package bytes, size and SHA-256 are verified before a package can be published.

Publication pipeline: Discover → Intake → Adapt → Validate → Preview → Publish. Failed checks keep an asset out of the public library. Read the full compatibility standard ↗

Discover components with 21st.dev

21st.dev is our discovery source, not a live feed of pre-approved GymPro motions. A selected component is retrieved through the authenticated 21st MCP/CLI workflow, adapted to a supported GymPro renderer, then published here only after verification.
