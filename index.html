The GymPro Compatibility Standard

We discover inspiration and components from sources such as 21st.dev, then adapt and verify them before they enter this catalogue. Third-party code is never shipped directly as an executable GymPro asset.

01 · Safe by designData-only package formats; no downloaded JavaScript, HTML, arbitrary CSS or remote frames.
02 · GymPro renderer fitSupported renderer, schema and app-version compatibility checked before listing.
03 · Lightweight & accessibleReduced-motion behavior, high-DPI handling, CPU budget and off-screen pausing reviewed where applicable.
04 · Theme-awareWorks with GymPro Base Theme and Integrated Studio Canvas Tone, including frosted-glass surfaces.
05 · Licence & provenanceSource, author, licence and attribution are recorded; incompatible terms are rejected.
06 · Integrity verifiedExact package bytes, size and SHA-256 are verified before a package can be published.

Pipeline: Discover → Import → Adapt → Validate → Preview → Publish. Failed checks keep an asset out of the verified catalogue.
